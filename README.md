## 📁 Featured Projects

### 🔧 [Physics-Guided AI for Friction Stir Welding Process Optimization](https://github.com/SatyaxLac)
*Python, Scikit-learn, Manufacturing Analytics, Machine Learning (2026)*
* Developed an AI-driven decision support system for Friction Stir Welding by integrating physics-based features with machine learning to predict weld yield strength.
* Designed a physics-guided data augmentation framework using Response Surface Methodology (RSM), Latin Hypercube Sampling (LHS), and process constraints to expand experimental data from 13 to 550+ realistic samples.
* Benchmarked five regression models and developed a Gradient Boosting surrogate model ($R^2=0.97$, $RMSE=3.5$ MPa) for process optimization, defect reduction, and data-driven manufacturing decisions.

### 🍎 [FreshFold – AI-Based Smart Food Freshness Detection System](https://github.com/SatyaxLac)
*SolidWorks, ANSYS Mechanical, ESP32, TensorFlow Lite, Embedded C (2025)*
* Designed a foldable edge-AI smart container, developing the CAD model, 270° hinge mechanism, material selection, and embedded hardware architecture for multimodal data acquisition.
* Integrated ESP32 with dual cameras, MQ-135, BME680, and IR temperature sensing to acquire synchronized visual, thermal, and environmental data for freshness assessment.
* Architected an offline edge-AI workflow using EfficientNet-Lite, sensor fusion, and TensorFlow Lite for real-time freshness prediction, inventory management, and spoilage alerts.
